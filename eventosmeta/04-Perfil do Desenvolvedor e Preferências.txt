## Estilo de Aprendizado

### Como Gosta de Aprender
1. **Contextualização:** Entender o "porquê" antes do "como"
2. **Passo a passo:** Não pular etapas
3. **Prático:** Aplicação imediata do conhecimento
4. **Incremental:** Construir conhecimento progressivamente
5. **Analogias:** Usar metáforas para conceitos complexos

### Exemplo de Boa Explicação
```markdown
## O que é um Service Layer?

Pense no Django como uma cozinha de restaurante:

- **Models:** São os ingredientes (dados)
- **Views:** São os garçons (pegam pedidos, entregam respostas)
- **Templates:** São os pratos montados (apresentação)
- **Services:** São os chefs (fazem a mágica acontecer)

Quando você tem uma receita complexa (lógica de negócio complicada),
você não pede pro garçom cozinhar. Você cria um chef especializado
(service) que sabe fazer aquilo bem.

### Na prática:
```python
# ❌ Errado: Lógica na view
def classificar_view(request):
    # 100 linhas de lógica aqui
    pass

# ✅ Correto: Lógica no service
def classificar_view(request):
    ClassificadorService.classificar_evento(evento)
```
```

## Workflow de Trabalho

### Processo Preferido
1. **Contextualização:** Entender o problema/necessidade
2. **Planejamento:** Definir o que será feito
3. **Validação:** Confirmar abordagem antes de implementar
4. **Implementação:** Gerar código completo
5. **Teste:** Validar se funciona
6. **Próximos passos:** Sugerir continuidade

### Tomada de Decisões
- **Você decide:** Assistente apresenta opções, desenvolvedor escolhe
- **Validação:** Sempre confirmar antes de executar mudanças grandes
- **Erros:** Analisar e corrigir juntos
- **Foco:** Uma tarefa por vez até conclusão

## Comunicação com IA (Claude)

### O que Funciona Bem
✅ Perguntas diretas e específicas
✅ Contexto claro do problema
✅ Mostrar o código atual quando possível
✅ Indicar o que já tentou
✅ Pedir explicações com analogias

### O que Evitar
❌ Perguntas muito abertas sem contexto
❌ Assumir que a IA sabe o estado atual do código
❌ Pedir múltiplas soluções ao mesmo tempo
❌ Mudar de assunto sem concluir o anterior
