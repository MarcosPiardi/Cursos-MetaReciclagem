## Modelos de Dados Principais

### App: eventos
- **Status** - Status dos eventos
- **Criterio** - Critérios de classificação (tipo_criterio, codigo, pontos)
- **Evento** - Cursos/eventos oferecidos
- **EventoCriterio** - Critérios aplicados ao evento (com prioridade)
- **Turma** - Turmas formadas
- **Horario** - Horários das turmas

### App: interessados
- **Interessado** - Cadastro de pessoas (CPF, dados pessoais, PCD, NIS)
- **Sexo** - Gênero
- **Fototipo** - Tipo de pele (cotas raciais)

### App: selecao
- **Inscricao** - Inscrição em eventos
- **StatusInscricao** - Status da inscrição
- **Classificacao** - Resultado da classificação
- **InscricaoCriterioAtendido** - Critérios que a inscrição atende

### App: academico
- **Matricula** - Matrícula em turma
- **StatusMatricula** - Status da matrícula
- **Avaliacao** - Avaliação final do aluno

## Autenticação

### Sistema Duplo de Autenticação

#### Staff (Administradores)
- Login via Django Admin
- Model: `accounts.Usuario`
- Autenticação padrão Django (username/password)
- Níveis de acesso configuráveis

#### Interessados (Público)
- Login customizado via CPF
- Model: `interessados.Interessado`
- Backend customizado: `InteressadoBackend`
- Autenticação por CPF + senha

## Otimizações de Performance

### Banco de Dados
```python
# Índices adicionados
class Interessado(models.Model):
    cpf = models.CharField(db_index=True)
    email = models.EmailField(db_index=True)
    nome = models.CharField(db_index=True)

class Inscricao(models.Model):
    evento = models.ForeignKey(db_index=True)
    interessado = models.ForeignKey(db_index=True)
    data_inscricao = models.DateTimeField(db_index=True)
```

### Queries Otimizadas
```python
# Select related para relacionamentos
inscricoes = Inscricao.objects.select_related(
    'evento', 
    'interessado'
).all()

# Prefetch para múltiplos relacionamentos
classificacoes = Classificacao.objects.select_related(
    'inscricao',
    'inscricao__interessado',
    'inscricao__evento'
).prefetch_related(
    'inscricao__inscricaocriterioatendido_set'
).all()
```

### Paginação
```python
from django.core.paginator import Paginator

def lista_inscricoes(request, evento_id):
    inscricoes = Inscricao.objects.filter(evento_id=evento_id)
    paginator = Paginator(inscricoes, 50)  # 50 por página
    page_number = request.GET.get('page')
    page_obj = paginator.get_page(page_number)
    return render(request, 'inscricoes.html', {'page_obj': page_obj})
```

## Comandos Úteis

### Setup Inicial
```bash
# Criar ambiente virtual
python -m venv venv

# Ativar ambiente (Windows)
venv\Scripts\activate

# Instalar dependências
pip install -r requirements.txt

# Configurar banco
python manage.py migrate

# Criar superusuário
python manage.py createsuperuser

# Carregar fixtures
python manage.py loaddata accounts/fixtures/*.json
python manage.py loaddata eventos/fixtures/*.json
python manage.py loaddata interessados/fixtures/*.json
```

### Desenvolvimento
```bash
# Rodar servidor
python manage.py runserver

# Criar migrations
python manage.py makemigrations

# Aplicar migrations
python manage.py migrate

# Shell Django
python manage.py shell

# Coletar arquivos estáticos
python manage.py collectstatic
```

### Classificação
```bash
# Classificar evento via comando
python manage.py classificar_evento --evento_id=1
```

### Testes
```bash
# Rodar todos os testes
pytest

# Com cobertura
pytest --cov

# Teste específico
pytest apps/selecao/tests/test_classificacao.py
```
